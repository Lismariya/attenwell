# **App Name**: BrainBoost Buddies

## Core Features:

- Noise Ninjas: A game to improve focus by identifying specific sounds amidst background noise.
- Track the Ball: A game to enhance attention by following a ball as it's hidden and moved around.
- Catch the Right One: A game to improve concentration by quickly identifying and catching the correct target.
- Memory Match: A game to boost memory skills through matching pairs of cards.
- Tap the Rabbit: A game to improve reaction time and focus by tapping rabbits as they appear.
- Find the Way: A puzzle game designed to improve problem-solving skills by navigating through mazes.
- Personalized Game Suggestions: An AI-powered tool that analyzes player performance and suggests the most beneficial game or exercise to play next, maximizing cognitive benefits.

## Style Guidelines:

- Primary color: Calm blue (#64B5F6) to promote a sense of peace and concentration.
- Background color: Light grey (#EEEEEE) to reduce distractions and eye strain.
- Accent color: Cheerful yellow (#FFEB3B) to highlight important elements and provide positive feedback.
- Body and headline font: 'PT Sans' for readability and a friendly appearance.
- Simple, clear icons for each game and function.
- Clean, uncluttered layouts for each game to minimize distractions and help with focus.
- Gentle animations and transitions to provide feedback and rewards without overstimulation.
