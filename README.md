# 🧠 AttenWell

> **A Digital Therapeutic Application for Children with ADHD**

AttenWell is an AI-assisted digital therapeutic application designed to support children with **Attention Deficit Hyperactivity Disorder (ADHD)** by improving attention, memory, executive functioning, and emotional well-being through interactive cognitive games, guided meditation, smart focus sessions, and caregiver progress tracking.

Developed as a final-year B.Tech Computer Science project, AttenWell combines gamification, digital therapeutics, and real-time progress monitoring to create an engaging learning environment while helping parents monitor their child's cognitive development.

---

## ✨ Key Features

### 🎮 Cognitive Training Games

AttenWell includes six interactive games, each designed to strengthen different cognitive abilities.

| Game | Purpose |
|------|---------|
| 🎧 Noise Ninjas | Improves selective auditory attention by identifying target sounds among distractions. |
| ⚽ Track the Ball | Enhances visual tracking, concentration, and sustained attention. |
| 🎯 Catch the Right One | Develops reaction time and selective attention while ignoring distractions. |
| 🧠 Memory Match | Strengthens working memory and visual memory through card matching. |
| 👾 Hit the Monster | Improves inhibitory control, attention, and reaction speed. |
| 🧩 Jigsaw Puzzle | Builds spatial reasoning, planning, and problem-solving skills. |

---

## ⏱️ Smart Focus Sessions

The application includes a Pomodoro-inspired focus timer integrated with **AI-powered face detection**.

Features include:

- 👀 Face presence monitoring
- ⚠️ Real-time focus alerts
- 📊 Session duration tracking
- ⏸️ Automatic pause detection
- 📈 Focus performance analytics

---

## 🧘 Guided Meditation

Children can participate in calming guided meditation sessions to reduce stress and improve emotional regulation.

Available session durations include:

- 5 Minutes
- 10 Minutes
- 15 Minutes
- 20 Minutes

---

## 🏆 Rewards & Progression

To encourage consistency, AttenWell includes a gamified reward system.

Children earn:

- 🪙 Coins
- ⭐ Achievement progress
- 🎖️ Level completion rewards

These rewards motivate regular participation while making therapy enjoyable.

---

## 👨‍👩‍👧 Parent Dashboard

Parents and caregivers can monitor the child's progress through an interactive dashboard featuring:

- 📈 Weekly progress charts
- 🎮 Game performance analysis
- ⏱️ Focus session statistics
- 🧘 Meditation history
- 🪙 Reward tracking
- 📊 Overall cognitive progress

---

## ☁️ AI Assistant

AttenWell features an animated cloud assistant that provides:

- Activity recommendations
- Progress-based suggestions

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/Lismariya/attenwell.git
```

## Navigate into the project

```bash
cd attenwell
```

## Install dependencies

```bash
npm install
```

## Configure Firebase

Create your own Firebase project and update the Firebase configuration in:

```
src/firebase/config.ts
```

## Run the application

```bash
npm run dev
```
